@startuml
title Диаграмма состояний\nЖизненный цикл товара в интернет-магазине «Лапки»

' Начальное состояние
[*] --> Черновик : Создание товара

' Состояние "Черновик"
state "Черновик" as Draft
Draft : Редактирование названия, цены,\nописания, изображения
Draft --> Draft : Изменение
Draft --> Опубликован : Публикация (администратор)

' Состояние "Опубликован"
state "Опубликован" as Published
Published : Доступен для просмотра,\nдобавления в корзину,\nизбранное, отзывы
Опубликован --> Черновик : Возврат в черновик
Опубликован --> Заархивирован : Архивирование (администратор)

' Состояние "Заархивирован"
state "Заархивирован" as Archived
Archived : Скрыт из каталога,\nнедоступен для покупки,\nсохранён в БД
Заархивирован --> Опубликован : Восстановление
Заархивирован --> Удалён : Полное удаление

' Состояние "Удалён"
state "Удалён" as Deleted
Deleted : Окончательное удаление,\nвосстановление невозможно
Удалён --> [*]

' Примечания к состояниям (вынесены отдельно)
note right of Draft
  Товар в процессе создания
  или редактирования
end note

note right of Published
  Товар активен и доступен
  пользователям (каталог,
  корзина, избранное, отзывы)
end note

note right of Archived
  Товар скрыт из каталога,
  но может быть восстановлен
end note

note right of Deleted
  Товар полностью удалён
  из системы. Восстановление
  невозможно.
end note

@enduml
