@startuml
actor "Пользователь" as User
participant "React SPA" as React
participant "Axios Interceptor" as Axios
participant "Django REST API" as API
participant "JWT Auth Middleware" as JWT
participant "ViewSet" as ViewSet
database "БД" as DB

== Регистрация / Логин ==
User -> React: Ввод email/nickname и пароля
React -> API: POST /api/auth/login/
API -> API: Проверка через EmailBackend
API -> DB: SELECT * FROM users WHERE (email=? OR username=?)
DB --> API: Данные пользователя
API -> API: Генерация access (30 min) и refresh (1 day)
API --> React: 200 OK {access, refresh}
React -> React: Сохранение токенов в localStorage
React --> User: Перенаправление на защищённую страницу

== Запрос списка купленных курсов (требует аутентификации) ==
User -> React: Запрос "Мои курсы"
React -> Axios: GET /api/courses/my_courses/
Axios -> Axios: Добавление заголовка Authorization: Bearer <access>
Axios -> API: GET /api/courses/my_courses/
API -> JWT: Проверка access токена (django-rest-framework-simplejwt)

alt Токен валиден
    JWT --> API: user_id = 123
    API -> ViewSet: Вызов MyCoursesViewSet
    ViewSet -> DB: SELECT * FROM purchased_courses JOIN course ...
    DB --> ViewSet: Список купленных курсов с прогрессом
    ViewSet --> API: Сериализованные данные (CourseSerializer)
    API --> Axios: 200 OK (JSON)
    Axios --> React: Данные курсов
    React --> User: Отображение списка

else Токен истёк (401 Unauthorized)
    JWT --> API: 401
    API --> Axios: 401 Unauthorized
    Axios -> API: POST /api/auth/token/refresh/ {refresh_token}
    API -> API: Проверка refresh токена (Simple JWT)
    API -> API: Генерация нового access токена
    API --> Axios: 200 OK {access}
    Axios -> Axios: Обновление access токена в localStorage
    Axios -> API: Повтор исходного запроса (с новым access)
    API --> Axios: 200 OK (JSON)
    Axios --> React: Данные курсов
    React --> User: Отображение списка
end
@enduml
