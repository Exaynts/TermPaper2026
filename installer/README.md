# MathJam — установка для Windows

Здесь описаны **два способа** получить приложение на Windows 10/11:

1. **Простой** — скачать готовый установщик с GitHub Releases (для пользователей).
2. **Ручной** — собрать установщик из исходников (для разработчиков).

---

## 🟢 Способ 1. Скачать готовый установщик (рекомендуется)

**Для кого:** обычные пользователи, которым нужно просто запустить приложение.

**Требования:**
- Windows 10/11 (x64)
- 500 МБ свободного диска
- Интернет только на время скачивания

### Установка

1. Перейдите на страницу релизов:
   **[github.com/Exaynts/TermPaper2026/releases](https://github.com/Exaynts/TermPaper2026/releases)**

2. Найдите последний релиз (например, `v1.0.0`).

3. В разделе **Assets** скачайте файл:
   ```
   MathJam_Setup.exe
   ```

4. Запустите `MathJam_Setup.exe` → «Далее → Установить».

5. Поставьте галочку **«Запустить MathJam»** и нажмите «Готово».

6. Откроется окно консоли с логами и браузер на `http://127.0.0.1:8000`. Приложение готово.

## 📁 Где искать важные файлы

При первом запуске MathJam создаёт в корне установки два текстовых файла со справочной информацией. Оба открываются в обычном Блокноте.

**Корень установки по умолчанию:**
%LOCALAPPDATA%\MathJam\


Чтобы открыть эту папку:

1. Нажмите **Win + R**.
2. Введите: `%LOCALAPPDATA%\MathJam`
3. Нажмите Enter.

### 📄 `ADMIN_CREDENTIALS.txt`

**Что внутри:** логин (email), никнейм и пароль администратора для входа в админку.

**Когда создаётся:** при первом запуске `start.bat`.

**Когда нужен:**
- Первый вход в админку Django: `http://127.0.0.1:8000/admin`
- Восстановление доступа, если забыли пароль.
- Передача доступа другому человеку.

**Если файл удалён или забыт пароль:**
1. Закройте MathJam.
2. Удалите `backend\db.sqlite3` в папке установки.
3. Запустите `start.bat` снова — администратор создастся заново, но **все данные (курсы, пользователи, прогресс) будут потеряны**.

### 📄 `EMAIL_SETUP.txt`

**Что внутри:** пошаговая инструкция, как подключить Gmail для отправки уведомлений на реальную почту.

**Когда создаётся:** при первом запуске, если email ещё не настроен. После того как вы заполните `EMAIL_HOST_USER` и `EMAIL_HOST_PASSWORD` в `backend\.env`, файл перестаёт создаваться (но остаётся лежать в папке — можно удалить вручную).

**Когда нужен:**
- Хочется получать уведомления о покупке курса и завершении уроков на свою почту.
- Нужно вспомнить, как получить «пароль приложения» Gmail.

**Если файл не нужен:** просто игнорируйте его — приложение полностью работает без email-рассылки. Уведомления будут выводиться в окно консоли `start.bat`.

### 🔎 Сводная таблица

| Файл | Что содержит | Где лежит | Когда создаётся |
|------|--------------|-----------|-----------------|
| `start.bat` | Запуск приложения | корень установки | при установке |
| `ADMIN_CREDENTIALS.txt` | Логин и пароль админа | корень установки | при первом запуске |
| `EMAIL_SETUP.txt` | Инструкция по Gmail | корень установки | при первом запуске, если email не настроен |
| `backend\.env` | Настройки Django, SMTP, БД | `backend\` | при первом запуске |
| `backend\db.sqlite3` | База данных (курсы, пользователи) | `backend\` | при первом запуске |

**Совет:** скопируйте `ADMIN_CREDENTIALS.txt` в надёжное место (например, в облако или менеджер паролей). Он лежит в системной папке и может быть потерян при переустановке Windows.

---

### Что дальше

- **Админка:** `http://127.0.0.1:8000/admin`
- **Данные администратора:** см. файл `ADMIN_CREDENTIALS.txt` в корне установки (подробнее ниже).
- **Настроить email:** см. файл `EMAIL_SETUP.txt` в корне установки (подробнее ниже).

### Удаление

Через «Параметры → Приложения» или через ярлык **Удалить MathJam** в меню Пуск. При удалении также стираются:
- база данных (`db.sqlite3`)
- загруженные картинки (`media/`)
- собранная статика (`staticfiles/`)
- `.env` (секреты)

## 🟡 Способ 2. Собрать установщик самому

**Для кого:** разработчики, которые хотят пересобрать `.exe` после правок.

**Требования:**
- Windows 10/11 (x64)
- [Inno Setup 6+](https://jrsoftware.org/isdl.php) (бесплатно)
- Python 3.13 (embeddable скачается автоматически)
- Интернет (для загрузки Python и pip-пакетов)

### Шаги

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Exaynts/TermPaper2026.git
   cd TermPaper2026/installer
   ```

2. **Настройте Python-окружение** (скачает embeddable Python, pip и все зависимости):
   ```cmd
   setup_python.bat
   ```

3. **Откройте `MathJam.iss`** в Inno Setup Compiler.

4. **Нажмите Build → Compile (F9).** Через 1–2 минуты появится:
   ```
   Resulting file: ...\installer\output\MathJam_Setup.exe
   ```

5. **Проверьте установщик** на чистой машине или ВМ.

6. **Опубликуйте в GitHub Releases:**
   - Откройте `https://github.com/Exaynts/TermPaper2026/releases/new`
   - Tag: новая версия (например, `v1.0.1`)
   - Title: `MathJam 1.0.1 — Windows x64`
   - Description: кратко опишите изменения
   - **Assets:** перетащите `output\MathJam_Setup.exe`
   - Publish release

### Структура

```
installer/
├── README.md                # этот файл
├── start.bat                # лаунчер приложения
├── MathJam.iss              # скрипт Inno Setup
├── setup_python.bat         # настройка Python + pip
├── backend/                 # портативная Django-сборка
├── python/                  # генерируется (в .gitignore)
└── output/                  # генерируется (в .gitignore)
```

### Что НЕ нужно коммитить в репозиторий

- `python/` — 150–250 МБ, восстанавливается через `setup_python.bat`
- `output/` — 300–400 МБ, публикуется через GitHub Releases
- `backend/.env` — секреты
- `backend/db.sqlite3` — данные пользователя

## ❓ Частые вопросы

**Q: Нужно ли устанавливать Python или Node.js?**  
A: Нет. Всё уже включено в установщик.

**Q: Можно ли установить в `C:\Program Files`?**  
A: По умолчанию приложение ставится в `%LOCALAPPDATA%\MathJam`, чтобы не требовать прав администратора. Переустановить в другую папку можно вручную, указав путь при установке.

**Q: Куда сохраняется база данных?**  
A: `%LOCALAPPDATA%\MathJam\backend\db.sqlite3` — это папка пользователя, данные не потеряются при обновлении приложения.

**Q: Как обновить приложение до новой версии?**  
A: Скачайте новый `MathJam_Setup.exe` из Releases и запустите — он перезапишет файлы, но сохранит `db.sqlite3` и `media/`.

**Q: Что если порт 8000 занят?**  
A: Откройте `start.bat` в блокноте и замените `8000` на другой порт (например, `8080`) в двух местах: `start ""` и `waitress --listen`.
